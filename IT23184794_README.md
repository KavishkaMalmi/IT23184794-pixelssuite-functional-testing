# Playwright Test Automation Project

This project contains automated end-to-end tests for image preview functionality using Playwright.

## Prerequisites

- Python 3.8 or higher
- Node.js (for Playwright browser binaries)

## Installation

1. Install the required Python packages:
   ```bash
   pip install playwright
   ```

2. Install Playwright browsers:
   ```bash
   playwright install chromium
   ```

## Running the Tests

To run the image preview tests and generate results:

```bash
python image_preview_test.py --url "https://www.pixelssuite.com/convert-to-png" --png "sample.png"
```

The execution results will be saved to `execution_results.csv` and screenshots will be stored in the `results` directory.
